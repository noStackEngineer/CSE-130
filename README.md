# CSE 130 Project Repository
Author: Dr. Andi Quinn

This repository is for CSE 130.  It serves two purposes:

1. As a way for us to share course infrastructure with you, such as the
   autograder and docker files

2. As a place to maintain the source code for the class.

## Course Infrastructure

The course infrastructure consists of autograder files and docker files:

* Autograder: The files requirements.txt and config.json under each of the asgn
  folders.  These configuration files help you work with the autograder.

* Docker: The files Dockerfile, docker-compose.yml, and
  .devcontainer/devcontainer.json.


## Maintaining your Source Code

We ask that you maintain the source code for each assignment in the associated
folder.  For example, place files related to assignment 2 into the folder asgn2.
Note: we will create folders for you throughout the course as necessary for the
assignments in this class.

## Resources

We will distributed source code for discussion sections and/or lectures into
associated folders.  For example, we'll put source code for discussion sections
into the discussion/ folder, with subfolders for each week.  We'll put source
code for lecture into the lectures/ folder, with subfolders for each week.
Note: you can abslutely edit these file! If you want to roll back to the
original (released) version, just use git's version control :-)
